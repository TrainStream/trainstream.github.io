投稿 Submit a stream

Found a camera that belongs here? Fill in the form and check the live preview. When you send it, a GitHub issue opens with everything filled in (you need a free GitHub account). A maintainer reviews it, fixes anything if needed, and publishes it. Your name can go on the ticket as thanks.

  1. Pictures: take screenshots of the stream, upload them to an image host (imgur, catbox…) and paste the direct image links. When it is published, the pictures are copied into the site so they never break.
  2. Text: write the name and description yourself. Put Japanese and English in the name if you can, e.g. 湯野上温泉駅 Yunokami-Onsen Station.
  3. Links: for YouTube, link the channel's /streams page. Video links change when a stream restarts.

🙏 This tool is built after the original trainstream-editor by altbdoor, which first made editing this site easy. It still works, and both tools save the camera list in the same format.

係員専用 Maintainers & publishers

Sign in with a GitHub personal access token to publish directly, review suggestions, and edit or retire streams. The token stays in this browser and is only sent to GitHub.

How do I get a token?
  1. Open GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Resource owner: the owner of {{ site.ts_repo }}. Repository access: Only select repositories → {{ site.ts_repo }}.
  3. Permissions → Repository: Contents: Read and write and Issues: Read and write.
  4. Generate, copy, and paste it below.

Trusted publisher without repo access? You don't need a token. Just use "Suggest a stream": if your GitHub username is listed in .github/publishers.yml, your suggestions are published automatically within a minute or two.
