MPV How to set up MPV

Some people use MPC-HC for the Yunokami stream, but for me personally it runs at low fps, so I am using mpv instead, which runs at a smooth 30 fps.

Download mpv from here: https://mpv.srsfckn.biz/

Config file (optional)

Now let's set up a small config file (not compulsory). We will set up the screenshot settings in it. You can download my config file from here: https://pomf.pyonpyon.moe/mgfhdc.zip (extract it from the zip).

You can see two commands already written there:

--screenshot-template=E:\My Videos\Pictures\train\1New\train-%n
--screenshot-jpeg-quality=96
  • The first command is where to save the screenshots. Change it to the path you want. The train-%n part is how screenshots are named, here "train-" plus the number of the picture in the folder.
  • The second command is the picture quality. 96 is a good balance between quality and file size for me.
  • While watching the stream press S to take a screenshot.

How to run a stream

  1. Make a shortcut to the mpv.exe file (right click → Send to → Desktop (create shortcut)).
  2. On the shortcut press right click → Properties.
  3. In the "Target:" field, at the end of the path after mpv.exe, put rtmp://114.160.7.45/livepkgr/live-cam003 (no quotation marks, and leave a space between mpv.exe and the stream link).
  4. Press OK and you are done. You can rename the shortcut to "Yunokami" or whatever you want.
