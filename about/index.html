このサイトについて About this site

Welcome to our (Train) Stream Guide! TrainStream is a hand-picked list of live cameras in Japan: train stations, train lines, streets, harbours, shrines, volcanoes and one bento shop. It started as a pastebin in a thread and has been a website since {{ site.ts_since | date: '%Y' }}.

Everything lives in one public GitHub repository, {{ site.ts_repo }}. The camera list is a single data file, _data/streams.json.
